# Витрина и блог KOK на axis-beauty.com — план

> Проект из [карты документов](../../README.md). Решения и почему — [decisions.md](decisions.md),
> ход работ — [journal.md](journal.md). План утверждён владельцем 17.11 с учётом внешней рецензии.

## Цель

Сделать корень `axis-beauty.com` самостоятельным каналом привлечения: дилер находит KOK в
поиске, видит пользу, регистрируется в `app.axis-beauty.com` и платит — без постоянных расходов
на рекламу. Мерило успеха — не посещения, а регистрации и оплаты, пришедшие с витрины.

## Как устроено

| адрес | что | где код |
|---|---|---|
| `axis-beauty.com/` | витрина, русский | `site/` в репозитории KOK |
| `axis-beauty.com/en/`, `/sq/` | английская и албанская версии | там же |
| `axis-beauty.com/blog/…` | статьи (сначала только по-русски) | там же, Markdown |
| `axis-beauty.com/tools/…` | бесплатные инструменты (P2) | там же |
| `app.axis-beauty.com` | только сервис: вход, регистрация, кабинет | приложение KOK |

- **Astro, статическая сборка.** React — только для по-настоящему интерактивного (инструменты).
- **Один репозиторий, два ресурса в Coolify.** У витрины свой Dockerfile, своя сборка и свой
  автодеплой: изменения в `src/`, `app/`, `server/` её не пересобирают.
- **Из приложения витрина берёт только данные:** цвета, шрифт Manrope, логотипы, словари
  переводов, тексты из `config/seo.json`. Компоненты приложения (`Landing.tsx` и др.) не
  импортирует: они завязаны на вход и API, и правка кабинета ломала бы сборку сайта.
- **Витрина не зависит от API приложения:** приложение лежит — витрина открывается.
- Главная `app.axis-beauty.com/` для гостя — сразу экран входа, закрытый от поиска (`noindex`), без
  перенаправлений: кто открыл `app.`, пришёл работать (решение владельца 17.11, вместо 301 на корень).
  В поиске одна витрина — корень. Вход, регистрация и кабинет остаются на `app.`.

## Этапы

### P0 — фундамент и запуск

1. Каркас Astro в `site/`: общие токены, языки RU/EN/SQ, шаблоны страниц и статьи.
2. Техническое SEO: свой canonical у каждой языковой версии, взаимные `hreflang` с `x-default`,
   локализованные title/description/H1, без автопереходов по языку браузера, sitemap,
   `robots.txt`, Open Graph, Schema.org (`SoftwareApplication`, `Organization`, `Article`,
   `BreadcrumbList`).
3. Счётчики GA4 и Метрики через ту же плашку согласия, что у приложения.
4. Источник клиента: при первом заходе — метки UTM и реферер в cookie на `.axis-beauty.com`;
   при регистрации на `app.` — запись клиенту в базу; оплата отмечается сервером по факту.
   События: `cta_click`, `login_click`, `pricing_view` (витрина), `sign_up`, `first_generation`,
   `purchase` (приложение) — сделаны к 18.11; `tool_used` — вместе с инструментами P2.
5. Ресурс в Coolify: проверочный адрес (sslip), закрыт от индексации.
6. Переезд домена — см. «Переезд» ниже.

### P1 — коммерческие страницы

Порядок — по частотам Wordstat (18.11, [wordstat.md](wordstat.md)): спрос у площадок, а не у «рекламы
автосалона» (меньше 800 в месяц против 50 000+ у Encar и che168, тысячи — «на русском»).

1. **Площадки:** `/encar/` и `/che168/` — только по-русски (спрос русскоязычный; пустых и машинных
   переводов не делаем). Сначала польза — как читать объявление, словарь полей, цена и пробег, — потом
   KOK для тех, кто продаёт. Carsensor отдельной страницы не получает (90 в месяц).
2. **«Тарифы»** — ближе всего к оплате.
3. **КП на автомобиль** (~600 в месяц с «образцом») — у нас готовый формат КП в PDF.
4. **«Возможности», «Примеры», «Для автодилеров»**, формат «карусель» — с прицелом на авто, за общий
   запрос «карусель для инстаграм» не боремся.

**Оферта и политика остаются на `app.`** (решение владельца 18.11, вместо переезда из первой редакции
плана): касса AnyPay проходила модерацию на этом адресе, а реквизиты владельца на витрину не выводим
(PR #41). Витрина ссылается на документы приложения; в поиске они остаются на `app.` (`INDEXED`).

Новые страницы под аудитории (импортёры, экспортёры) — не делаем: спроса в Wordstat нет.

### P2 — бесплатные инструменты (`/tools/`)

1. Калькулятор «авто под ключ» — без ИИ, расходов нет.
2. «Вставь ссылку Encar/che168/Carsensor — получи описание для Instagram» — демо самого KOK
   на наших ядрах. С лимитами и защитой от ботов; нагрузку на Encar считать отдельно (он режет
   наши адреса).

Генераторы на ИИ для анонимных посетителей — только с лимитами: каждый вызов стоит денег.

### P3 — блог и масштабирование

Кластеры на старте: маркетинг для автодилеров (4), авто из Кореи (3), авто из Китая и Японии (3),
создание автомобильного контента (4), ИИ-инструменты для автобизнеса (3). Первыми — темы,
близкие к покупке: видео автомобиля для продажи, Reels для автосалона, оформление КП на авто,
автоматизация Instagram автоэкспортёра. Дальше 1–2 статьи в неделю; темы — по запросам из
Search Console. Черновики пишет Claude, по сути проверяет владелец; албанский — носитель.

## Переезд домена

DNS — Cloudflare (доступ у владельца), корень до 17.11 указывал на Vercel (магазин фар,
384 адреса `/headlights/…`). Search Console — наш, на весь домен.

Перед переключением:
- выгрузить из Search Console статистику старых страниц за 12 месяцев: трафик и внешние ссылки;
- старым `/headlights/*` — **410**; 301 — только тем, у кого есть внешние ссылки и уместная замена;
- проверить HTTPS и режим SSL в Cloudflare (Full strict); проксирование записи может помешать
  выпуску сертификата Let's Encrypt в Coolify — проверить заранее;
- проверить записи A, AAAA и CNAME, сохранить прежние для отката;
- проверить canonical, sitemap, редиректы и коды ответов на проверочном адресе;
- проверить, что вход, регистрация и cookies `app.` не задеты.

После: запись A корня → наш сервер, `www` → корень; Search Console и Вебмастер — sitemap;
проект на Vercel держим ещё 14 дней как запасной и только потом отключаем.

## Критерии приёмки

- Lighthouse Performance 95+, LCP ≤ 2,5 с, CLS ≤ 0,1, INP ≤ 200 мс.
- Основной текст страниц доступен без JavaScript.
- Все индексируемые страницы — в sitemap; у каждой свой canonical и Open Graph.
- Картинки — WebP/AVIF.
- На телефоне 375 px нет горизонтальной прокрутки.
- Нет пустых языковых страниц и машинных «переводов-заглушек».
