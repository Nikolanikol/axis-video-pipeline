## 17.11 — вход из витрины: настоящие адреса и вошедший владелец (не закоммичено)

- **Находка владельца:** «Войти» с витрины вело вошедшего в кабинет человека на «Такой страницы нет» —
  роутер приложения принимал `#/login` за раздел. Плюс на проде пока старая версия, которая `?lang=` и
  `#/login` не знает вовсе.
- **Исправлено:** ссылки — настоящие адреса `app…/login?lang=` и `/register?lang=`; приложение разбирает
  их до роутера (`app/entry.ts`): вошедшему — главная кабинета, гостю — нужное окно. Старая версия
  приложения на этих адресах просто показывает свою главную (прод уже отвечает 200).
- **Адрес приложения на витрине — `PUBLIC_APP_URL`** (по умолчанию боевое app.): для превью PR —
  адрес превью приложения, локально — копия. Проверено локально (`PUBLIC_APP_URL=http://localhost:3214`,
  копия без базы = вошедший владелец): «Войти» → главная кабинета, адрес `/`, без «Такой страницы нет».
  Окно регистрации гостю — на превью (локально без базы гостя нет).
- `/favicon.ico` у витрины — тот же файл, что у приложения (браузеры просят его сами, было 404).
- **Порядок выкладки:** сначала приложение (ему эти правки нужны и без витрины), потом переключение домена.

## 17.11 — P0: сервер, вход из витрины, счётчики, источник клиента, замер (не закоммичено)

- **Сервер витрины:** `site/Dockerfile` (сборка из корня репозитория: копирует только `site/`, словари,
  `config/seo.json`, логотипы и образцы — правки кода приложения образ витрины не меняют) и
  `site/nginx.conf`: `/headlights/*` → **410**, своя 404 (`src/pages/404.astro`, noindex), кэш
  `_astro` на год, логотипы и образцы на сутки, страницы на 5 минут, gzip. **Образ локально не собирали** —
  Docker на Mac не запущен; проверится на ресурсе Coolify.
- **Вход из витрины в приложение:** ссылки `app.axis-beauty.com/?lang=<язык>#/register` и `#/login`.
  В приложении: `?lang=` ставит язык (`app/i18n/index.tsx`), `#/register|#/login` открывает окно
  (`app/Landing.tsx`). Язык проверен на копии без базы (:3214); окно регистрации без базы не проверить —
  гостю витрина показывается только с базой, проверим на превью.
- **Счётчики:** `site/src/components/Analytics.astro` — те же GA4 и Метрика, что у приложения, тот же
  режим согласия; включаются только на `axis-beauty.com`/`www`. События: `cta_click` (место кнопки),
  `login_click`, `pricing_view`. Локально проверено, что ничего не грузится; плашку и отправку проверить
  на боевом адресе. **Владельцу:** в Метрике добавить `axis-beauty.com` в адреса счётчика 113666993,
  в Вебмастере — сайт `axis-beauty.com`.
- **Источник клиента:** витрина запоминает при первом заходе `utm_*`, внешний `ref` и первую страницу
  (`site/src/components/Source.astro`, память вкладки) и дописывает в ссылку при нажатии; приложение
  забирает (`app/source.ts`) и отправляет с регистрацией; сервер чистит (`cleanSource`) и пишет в
  `smmaker_users.source` (**миграция 022**). Проверено: витрина → ссылка → приложение (язык и метки
  на месте, адрес очищен); фильтр сервера отбрасывает лишние поля и режет длинные строки.
  Запись в базу при регистрации — на превью. В админке источник пока не показывается.
- **Замер Lighthouse** (телефон, готовая сборка через `astro preview`, без gzip): скорость 99,
  доступность 100, лучшие практики 100, SEO 100; LCP 2,3 с, CLS 0, блокировка 0 мс.
- **Тесты приложения не гоняли** (правило: по слову владельца); `tsc --noEmit` чистый.
- Осталось в P0: ресурс в Coolify (нужен push ветки), переезд домена.

## 17.11 — P0: каркас витрины (ветка `feat/site`, не закоммичено)

- **`site/` — Astro 7.3.8**, статическая сборка, папка `axis-video-site` (worktree). 7.4 не взяли:
  ему нужен Node 22.22+, а на Mac 22.13; 7.3.8 вышел 08.10. По той же причине sitemap — своя
  страница (`src/pages/sitemap.xml.ts`), а не пакет `@astrojs/sitemap` (тянет sitemap@10 под Node 22.22).
- **Данные из приложения, без копий текстов:** словари `app/i18n` (ru/en/sq, `names.ts`, `faq.ts`),
  вопросы и русские SEO-тексты — `config/seo.json`, образцы — `public/landing/samples.json`.
  `scripts/shared.mjs` перед сборкой копирует логотипы KOK, площадки и образцы в `site/public/shared`
  и берёт условия из `GET /api/public/offer` (снимок — `src/snapshot/offer.json`, без реквизитов владельца).
- **Страницы:** `/`, `/en/`, `/sq/` — главная (первый экран, шаги, образцы, условия и тарифы,
  вопросы, призыв), шапка с языками-ссылками, подвал. Живое превью Remotion заменено роликом-образцом
  (плеер весит сотни КБ скриптов). Вход и регистрация — ссылки на `app.axis-beauty.com/`.
- **SEO:** у каждой версии свой title/description/canonical, взаимные `hreflang` + `x-default`,

- **В приложении:** в `app/i18n/names.ts` добавлены названия тарифов (Basic/Standard/Pro, Bazë) —
  без них английская и албанская витрины показывали «Базовый».
- **Проверено локально** (`npm run dev` в `site/`, :4321): три языка, заголовки, canonical и hreflang,
  5 вопросов и 3 блока разметки на каждой странице, ширина на телефоне 375 без прокрутки вбок,
