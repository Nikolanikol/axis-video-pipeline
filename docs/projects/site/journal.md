  падал на `import.meta.env` витрины.

  прокрутки вбок, ссылки на витрину, консоль чистая; для боевого имени (`Host: app.axis-beauty.com`):
  главная `noindex`, оферта и политика без него, `sitemap.xml` — два адреса; `npm run build` проходит.
  `tsc` — чисто. **Не проверено:** вход, `/register` с витрины и ссылки из писем с базой — на превью PR;
