# Решения по подготовке рабочего инструмента к релизу

## 19.11.2026 — порядок работы

По поручению владельца идём последовательно по [плану](plan.md): сначала исправляем
ошибку PDF и мобильный доступ к готовой работе, затем сохранность правок, условия
запуска и удобство экранов. Крупные дополнения откладываем до стабилизации.

Каждый этап имеет проверяемый результат. Локальная готовность и подтверждение боевого
исправления фиксируются раздельно; существующий порядок проверки владельцем, коммитов
и публикации сохраняется.

## 19.11.2026 — печать КП через CDP

После воспроизведения зависания CLI в Linux используем установленный Chromium Remotion
через `Page.printToPDF`. Другой браузер, PDF-библиотеку или сервис не добавляем. Общее
HTML-представление и очередь сохраняются; ресурсами отдельного процесса владеет модуль
печати. Причина выбора и фактические проверки — в [журнале](journal.md).
