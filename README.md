# AXIS Video

KOK («Контент одной кнопкой»; внутреннее имя — SMMAKER) — контент для автодилеров: реклама по лотам (1080×1920, 30 fps), монтаж обзоров
(60 fps) и карусели слайдов в четырёх форматах. С базой — кабинеты компаний с
самостоятельной регистрацией и кредитами (см. «Вход и кабинеты»); без базы — один владелец без входа. Фирменный
стиль компании — палитра, шрифты и логотип в «Настройки → Бренд».

Зачем проект устроен именно так, что сколько стоит и какие есть дыры — в [CONTEXT.md](CONTEXT.md).

| пайплайн | инструменты |
|---|---|
| **Реклама авто** (`#/ads`) | «Ролик по лоту» — лот → превью → mp4 в выбранном формате |
| **Обзоры авто** (`#/reviews`) | «Монтаж обзора» — шортсы 15–60 с из своих вертикальных съёмок |
| **Карусели авто** (`#/carousels`) | «Карусель по ссылке» — объявление Encar → слайды в выбранном формате |
| **Настройки** (`#/settings`) | «Профиль», «Бренд» — общие для всех пайплайнов |

В «Рекламе авто» ролики собираются по **форматам** (вариациям). Сейчас есть один:

| формат | что это |
|---|---|
| `price-ad` — «Авто с ценой» | 15 с: хук → характеристики → маршрут и цена до порта → призыв |

## Веб-интерфейс

```bash
npm install
npm run app          # откроется http://localhost:3210
```

Главная — карточки пайплайнов и их инструментов; в шапке — переход между пайплайнами, адрес страницы (`#/<пайплайн>/<инструмент>`) можно сохранить в закладки.

- **Лот** — авто, характеристики, цена (만원 + курс или сразу $), фото: загрузка и порядок перетаскиванием. Автосохранение.
- **Размыть** на фото — выделяешь мышкой номер или лишнее, размытие видно сразу. Области хранятся в лоте и накладываются на оригинал, поэтому их можно убрать или поправить в любой момент.
- **Настройки → Профиль** — компания, язык, **модель цены** (экспорт/внутренний рынок) и контакты; справа превью. Тексты постов подставляются сами под язык и режим — их писать не нужно.
- **Настройки → Бренд** — имя, цвета и логотип; рядом образец, на котором видны все настройки разом.
- **Формат** выбирается над превью; один лот можно отрендерить в разных форматах.
- **Превью** обновляется сразу, в том числе с несохранёнными настройками профиля и бренда. **Рендер** берёт сохранённое.
- **История роликов** под рендером: у каждого — управление по состоянию. В очереди/в работе — «Отменить»; готовый — «Скачать mp4», «Смотреть», «Пересобрать», «Удалить»; ошибка или отменён — «Пересобрать», «Удалить». Удаление убирает и файлы.

На Mac сервер слушает только `127.0.0.1`; с базой вход обязателен и там (`npm run admin` заводит владельца). На проде до выкладки кабинетов — Basic Auth, см. «Вход по паролю» в [CONTEXT.md](CONTEXT.md). После правок `src/` и `config/` сервер сам пересоберёт проект Remotion при следующем рендере. **Правки в `server/` требуют перезапуска** — иначе интерфейс шлёт новое поле, а сервер его молча отбрасывает: в превью изменения видно (оно считается в браузере), а в готовом ролике нет.

Важно для кода рендера: `renderMedia` рендерит props, переданные в `selectComposition`. Для других props композицию нужно выбрать заново.

## Вход и кабинеты (SMMAKER)

С базой (`DATABASE_URL`) инструмент становится кабинетами компаний: без входа он не
открывается. Без базы — по-старому, один владелец без пароля.

- **Клиент**: сам регистрируется на странице входа — имя, почта, телефон, пароль (компания
  по желанию). На почту приходит код: после подтверждения — 7 бесплатных кредитов на
  30 дней. Забыл пароль — «Забыли пароль?» на входе, ссылка придёт на почту. В шапке — компания и
  остаток; «Мой кабинет» — остаток, подписка и до какого числа, тарифы, докупка и кнопка
  WhatsApp. За 5 дней до конца подписки — полоса «заканчивается, сгорят N кредитов».
  Кредиты кончились — готовое можно смотреть и скачивать, новое — после продления.
- **Кредиты**: цена генерации написана на кнопке (карусель 1, ролик 3, обзор 10 —
  `config/credits.json`). Списываются при запуске, сначала те, что раньше сгорают; если
  ролик упал или его отменили — возвращаются сами. Подписка на месяц (Базовый 30 кр.,
  Стандарт 50, Про 90): кредиты сгорают в конце месяца; докупка сгорает вместе с подпиской.
  В «Моём кабинете» — история кредитов построчно.
- **Сотрудники платформы**: владелец заводится командой `npm run admin -- почта` (пароль
  спрашивается в терминале). Вкладка «Админка»: клиенты-лиды с телефонами, остатком,
  числом генераций, подпиской и оплатами; блок «Пора продлевать»; начисление подписки или
  докупки (менеджер и админ); бонус, прайс подписок и докупки
  и назначение менеджеров (только админ). Контакты для покупки — `config/platform.json`,
  номер WhatsApp можно задать переменной `SMMAKER_SALES_WHATSAPP`.

## Бренд

`config/brand.json` — имя, цвета, шрифты и файлы логотипов.

**Цвета выбираются палитрой** («Настройки → Бренд → Палитра»): восемь готовых палитр из
`config/palettes.json` — медь на графите (AXIS), золото, сталь, синий, красный, изумруд,
оранжевый, белый минимализм. Каждая карточка нарисована своими цветами; каждая палитра
проверена на читаемость текста и цены. Свои цвета — под «Тонкой настройкой»: там же видно,
если что-то перестанет читаться. Новая палитра добавляется в `config/palettes.json` и
обязана пройти `npm test`.

```json
{
  "name": "K-AXIS MOTORS",
  "bg": "#111111", "copper": "#B8734A", "...": "остальные цвета",
  "fonts": {"head": "Oswald, sans-serif", "body": "Montserrat, sans-serif", "url": ""},
  "style": {"gradient": true, "radius": 1},
  "assets": {"logoStacked": "brand/logo-stacked.svg", "...": "остальные файлы"}
}
```

**Логотип загружается в интерфейсе** («Настройки → Бренд»): PNG, JPG, WebP или SVG до
10 МБ, от 300 точек. Готовить файл не нужно — приёмник сам уберёт ровный фон (белый,
чёрный, любой однотонный), обрежет пустые поля, уменьшит большое и переведёт SVG в PNG.
Не подойдут только фото и текстуры: у них пёстрый фон. Если логотип тёмный или часть его
тёмная (вариант для светлого фона), появится предупреждение — на тёмном слайде он пропадёт.
Превью показано на цвете фона слайда. Кнопки рядом: «Оставить фон как был», если
автоматика ошиблась, и «Без логотипа — название текстом». Файл ложится в
`data/workspaces/<компания>/brand/` и ставится везде, где виден логотип: крупно на финале,
полосой вверху кадра и водяным знаком.

**Оформление** — два переключателя там же: медь градиентом или плоским цветом, углы острые,
мягкие или круглые. Углы задаются множителем: он меняет плашки, рамки, «таблетки» и точки
списка разом, сохраняя их соотношение.

**Пара шрифтов выбирается в интерфейсе** («Настройки → Бренд»). Девять пар в
`config/fonts.json`, каждая нарисована своими шрифтами прямо в списке — по названию их
не отличить. Все умеют кириллицу и отдают настоящие 500/600/700: шрифты только с латиницей
(Bebas Neue) и без нужных начертаний (PT Sans, Play) в список не попали намеренно.

Первая пара — встроенная, Oswald + Montserrat: идёт пакетами вместе со сборкой и работает
без сети. Остальные грузятся по сети при рендере; не загрузились — кадр рисуется системным
шрифтом, а не ждёт.

`fonts.url` — таблица стилей Google Fonts, если нужен свой шрифт мимо списка: тогда `head`
и `body` указывают его семейства. Пусто — берутся встроенные Oswald и Montserrat.

В `assets` годится и путь внутри `public/`, и полная ссылка.

Ни один цвет в вёрстке не зашит: всё через тему, и она приходит параметром в композицию.
Поэтому одна сборка проекта умеет рисовать в любых цветах — это задел на несколько брендов.

### Лот

| поле | что это |
|---|---|
| `format` | последний выбранный формат (`price-ad`) |
| `brand`, `model`, `trim`, `year` | заголовок хука; `trim` необязателен |
| `specs[]` | 4 строки характеристик на языке постов (до ~26 символов) |
| `carPriceUsd` | цена авто в $ **или** |
| `carPriceKrw` + `krwPerUsd` | цена в ₩ и курс (₩ за $1) |
| `photos[]` | 0 — хук, 1–2 — характеристики, остальные — запас |
| `note` | заметка, в ролик не попадает |
| `freightUsd`, `whatsapp`, … | поля профиля можно переопределить на этот лот; `whatsapp: null` — скрыть номер |

**Лот по ссылке Encar.** Над формой — поле для ссылки на объявление. «Подтянуть из Encar»
показывает машину и все фото объявления: рекомендованные ракурсы (перед, зад, салон,
приборы) уже выбраны, нажатием фото добавляется или убирается, номер на фото — его место
в лоте. Дальше «Новый лот по ссылке» или «Подтянуть в этот лот». Заполняются марка,
модель, комплектация, год, характеристики на языке профиля (словари карусели), цена в ₩
и курс на сегодня. Уже заполненный лот без спроса не перетирается. Фото копируются к нам
(размытие и порядок работают, ролик не зависит от объявления). Бесплатно.

**Курс ₩/$** сервер берёт раз в сутки (open.er-api.com) и хранит в `data/rates.json`.
В форме у поля курса — «сегодня 1 358,97 · подставить», если в лоте курса нет или он
отличается больше чем на 0,5%.

Модель цены задаётся в профиле: **export** — цена авто + фрахт, на постах маршрут и «цена до порта»; **domestic** — цена как есть, без фрахта и порта. Без цены ролик — черновик с «XX XXX».

## Монтаж обзора

Своё вертикальное видео обхода машины (iPhone: `.mov`, HEVC, 4K 60 fps, поворот в метаданных) → шортс 9:16.

1. **Видео.** Загрузка (до 4 ГБ, до 10 мин). Сервер делает рабочую копию H.264 **до** 1080×1920 в 60 fps (как сам ролик — `REVIEW_FPS`) с частыми ключевыми кадрами (поворот применяется сам) и миниатюры каждые 0,5 с. Всё — ffmpeg из Remotion.
   > **`FFMPEG_PATH` на свою сборку ставить нельзя.** В сборке Homebrew нет фильтра `zscale`, на котором держится перевод HDR, — копия соберётся без него, и картинка выйдет вялой. В сборке Remotion фильтров всего полсотни, но `zscale` среди них есть. Полный ffmpeg годится для отдельных задач и замеров, но не для подготовки копии.
   **HDR переводится в BT.709.** iPhone пишет Dolby Vision (10 бит, HLG, BT.2020); без перевода картинка в ролике вялая. Съёмка в HDR помечена в описании видео; тонмаппинг 4K идёт на процессоре и заметно дольше обычной сборки.
   **Маленькие исходники не растягиваются.** Если залили видео меньше 1280 по длинной стороне, под кнопкой появится предупреждение: это сжатая копия (например, из мессенджера), и резкость уже потеряна безвозвратно.
   **«Пересобрать видео»** делает рабочую копию заново из того же файла — нужно, когда поменялась обработка. Фрагменты и распознанная речь остаются.
2. **Таймлайн.** Видео + полоса миниатюр с фрагментами. Пробел — пуск, ←/→ — 0,5 с (Shift — кадр), I/O — отметки начала/конца, Enter — добавить фрагмент. Выбранный фрагмент: «Сдвинуть сюда», «Конец здесь», «▶ Фрагмент».
3. **Фрагменты.** Тип: хук (марка/модель/год из лота), плашка (текст, «медью» — акцент), финал (цена до порта с оговоркой и контакты). Скорость 1×/2×/3×.

   **«Обзор целиком»** — единственная раскладка в интерфейсе: три фрагмента (заставка 3 с, весь материал, финал 4,5 с), материал не режется. Хвост короче доли (до 0,5 с) не попадает: длины кратны доле, иначе стык прыгает. «Очистить» убирает фрагменты.

   Раскладки, режущие материал (шаблон v1, «под озвучку», чистка пауз), из панели убраны: обзор снимается одним кадром, и склейки ломают и картинку, и синхрон с начиткой. Код и тесты на месте в `src/shared/timeline.js` — возвращать по одной и каждую проверять полным прогоном.

   Длина фрагмента привязана к доле 0,5 с — склейки попадают в музыку 120 BPM. Исключение — фрагменты с флагом `exact`: там ритм задаёт речь, и длина считается по кадрам.
4. **Речь и субтитры.** Два языка задаются отдельно: **язык речи в видео** (для распознавания) и **язык субтитров и озвучки** (на него переводим; по умолчанию — язык профиля). «Распознать речь» — ElevenLabs Scribe: слова с таймингами, из них собираются строки субтитров (минута речи — пара секунд, доли цента). Строки можно править, рядом поле перевода; «Пересобрать строки» режет уже распознанные слова заново и ничего не стоит. Субтитры показываются на фрагментах с плашками — на хуке и в финале свой текст.
   **Перевод заполняется вручную** — автоперевода в инструменте нет.
5. **Озвучка перевода.** «Озвучить перевод» читает **весь текст одним запросом**: модель держит интонацию между фразами и сама расставляет паузы, а времена фраз берутся из разметки по символам. Диктор выбирается из реестра `config/voices.json` (у каждого языка своя модель и настройки: македонский умеет только `eleven_v3`, для английского взят `eleven_multilingual_v2` — на нём клон звучит без акцента). Любого диктора можно послушать до синтеза — одна фраза стоит копейки. Кэш — хэш от всего текста с голосом, моделью и языком. Языки без голоса (албанский) помечены в списке: субтитры на них делать можно, озвучку нет.

   Дорожка озвучки лежит **отдельным слоем поверх всего ролика** (`voicePlan`), а не внутри фрагментов: граница фрагмента не должна обрывать фразу. Если начитка длиннее съёмки, поджимаются паузы между фразами, а не сама речь.
   Логотип вверху кадра идёт со своей подложкой (градиент + тень на буквах) — поверх съёмки он иначе теряется на светлом небе. В рекламных форматах она отключена: там верх кадра затемняет `Shade`.
6. **Цвет съёмки.** Экспозиция, контраст, насыщенность, теплота — ползунками, от −100 до +100; двойной щелчок возвращает ползунок в ноль. Три пресета: «Пасмурно», «Солнце», «В помещении». Накладывается только на видео — логотип, плашки и карточка цены остаются фирменных цветов. Превью считает сразу.
7. **Звук.** Громкость диктора; живой звук с видео (на ускоренных фрагментах выключен). При включённой озвучке живой звук выключается — иначе в кадре говорят два голоса разом, — и ползунок честно об этом пишет. Фоновой музыки нет (убрана из продукта).

   **«Выделить звуки машины»** — проба. Модель разделения (Demucs) убирает из дорожки голос, оставляя двери, двигатель и шаги; такую дорожку можно подложить под начитку. Голос убирается не начисто, поэтому шаг ручной и выключается галочкой. Кнопка появляется, только если установлено окружение `.venv-demucs` (см. `server/ambience.mjs`) — зависимостью проекта это не является.
8. **Рендер** — как у лотов: mp4 и раскадровка, с управлением в истории.

Файлы проекта: `data/workspaces/<компания>/reviews/<id>/` — `review.json`, `source.*`, `proxy-<версия>.mp4`, `thumbs-<версия>/`, `voice/track-<хэш>.mp3`, `ambience-<версия>.m4a`.
Таймлайн, раскладки и чистка фрагментов — `src/shared/timeline.js`, субтитры — `src/shared/subtitles.js`, сборка текста и укладка озвучки — `src/shared/narration.js`, дикторы — `src/shared/voices.js`, цветокоррекция — `src/shared/colour.js`, список языков — `src/shared/languages.js` (все общие для ролика, интерфейса, сервера и тестов); ролик — `src/reviews/ReviewShort.tsx` (композиция `review-short`, длительность считается по фрагментам), оформление поверх съёмки — `src/reviews/Overlays.tsx`.

Важно для правок: **плашка накладывается, а не режет видео**. Съёмка идёт непрерывными кусками — `videoRuns` в `timeline.js` сливает соседние фрагменты, идущие подряд по исходнику с той же скоростью, в один элемент. Каждый лишний элемент перематывает файл, и на стыке дёргается кадр. Оформление живёт отдельным слоем и к нарезке не привязано. Распознавание и синтез — `server/speech.mjs`, разделение звука — `server/ambience.mjs`, проекты обзоров — `server/reviews.mjs`; в тестах вместо сервиса поднимается подставной сервер, который отдаёт и разбор речи, и звук, так что тесты не ходят в сеть и ничего не стоят.

Сохранение формы шлёт версию, с которой её открыли (`baseUpdatedAt`). Если обзор за это время изменили в другом месте — вторая вкладка, распознавание, озвучка — сервер отвечает 409 вместо тихого затирания.

Ссылка на объявление Encar → слайды для Instagram и TikTok. Ниже — слайды «Классики»
(7 картинок 1080×1920); остальные форматы описаны после таблицы.

| слайд | что на нём |
|---|---|
| 1 | обложка: марка, модель, комплектация, год, топливо, коробка, пробег, смены владельцев |
| 2 | история: страховые случаи целиком — детали, работы, окраска — или «No accident record» |
| 3 | салон |
| 4 | оснащение и безопасность |
| 5 | характеристики |
| 6 | цена в Корее |
| 7 | призыв: WhatsApp и сайт |

Данные берутся **через шлюз в соседнем проекте kmotors** (`KMOTORS_API_URL`,
`KMOTORS_API_SECRET`), а не напрямую: Encar блокирует адреса дата-центров. Ракурсы
подбираются по кодам фотографий (перед, зад, салон, панель) — иначе на обложку попадает
снимок диска. Опции ранжируются по значимости, а не идут подряд. Фото грузятся в полном
размере (`?impolicy=heightRate&rh=1080`).

Слайд можно открыть на весь экран и скачать по одному или все разом. Сборка идёт
**картинками, а не видео** (`renderStill`, композиция из семи кадров при fps 1): около
четырёх секунд и 408 МБ. У собранной карусели есть **«Пересобрать»** (тот же сбор по номеру:
свежие данные, тот же брендбук) и **«Удалить»**; в списке «Собранные раньше» удаление — у
каждой строки.

> **Instagram режет 9:16 до 4:5** — по 285 точек сверху и снизу. Весь текст обязан жить
> внутри `SAFE` (`src/carousel/Slides.tsx`); фото может выходить за неё. Правку слайда
> проверяй обрезанной копией, а не целой:
> `ffmpeg -i slide.png -vf "crop=1080:1350:0:285" ig.png`.
> На 1080×1350 не переходим: TikTok показал бы такую картинку с полями.

Файлы: `src/carousel/` — вёрстка, `server/carousel.mjs` — данные и сборка,
`src/shared/encarLink.js` — разбор ссылки, `app/carousels/CarouselTool.tsx` — экран.
Готовое лежит в `data/workspaces/<компания>/carousels/<id>/`.

**Формат** выбирается карточкой перед сборкой: «Классика» (7 слайдов 9:16), «Витрина»
(9 квадратов), «Разворот» (6 слайдов 4:5), «Полная» (12 квадратов с деталями, галереей и
«почему мы»). «Пересобрать» — те же компоновка и фразы на свежих данных; «Другой вариант» —
та же машина с другой компоновкой и другими фразами. Кнопка связи на финале — WhatsApp или
Telegram, как выбрано в профиле. Новый формат — строка в `config/carousel-formats.json`.

**Язык слайдов** — из «Языка постов» в профиле: английский или русский (македонский и
другие пока получают английский). Опции, топливо и коробка переводятся словарями kmotors —
слово то же, что на kmotors.shop/ru. Новые опции в kmotors — пересобрать словарь:
`node tools/sync-kmotors-dict.mjs ~/Desktop/recup/KMotors-1`.

## Форматы

Два формата ролика по лоту, выбираются над превью:

- **Авто с ценой** (`price-ad`, 15 с): хук → характеристики на двух фото → маршрут и цена →
  призыв. Берёт три фото.
- **Галерея** (`gallery-ad`, 17,5 с): хук → пять фото по секунде с растворением → стопка из
  трёх фото с характеристиками → цена → призыв (под фото галереи — модель и год). Берёт до 9
  фото: 1-е — хук, 2–4-е — стопка,
  дальше — галерея (не хватает — добирает по кругу). Сделана под объявления Encar.
  Место каждого фото можно выбрать руками — список под миниатюрой: «Авто» (по порядку),
  «Хук», «Стопка», «Галерея», «Не брать». Подпись под фото показывает, куда оно попадёт.

Горизонтальные фото (Encar — 16:9) в обоих — крупной полосой 1150 px, верх снимка срезан
(там значок Encar); камера не ездит, только лёгкий наезд. Цена — в валюте профиля: при KRW
в вонах.

```
config/formats.json          реестр: id, сцены (from / frames / кадр раскадровки), bpm, requires, photoRoles, texts
src/shared/                  общее для всех форматов
  model.ts                   логика без React: лот поверх рынка, цена, реестры
  ui.tsx                     тема, шрифты, медь, фото, затемнение, логотип
  music.tsx                  фоновая музыка с подгонкой темпа под формат
  types.ts                   типы
src/formats/<id>/            сцены конкретного формата
src/formats/index.ts         id формата → компонент
src/Root.tsx                 каждый формат — композиция Remotion с тем же id
```

Новый формат:
1. Запись в `config/formats.json`: сцены подряд, склейки — на долях темпа `bpm`, тексты — ключи, которые ищутся в текстах профиля.
2. Папка `src/formats/<id>/` с компонентом `(props: AdProps)`: `resolveAd(props)` даёт лот поверх данных профиля, тайминги сцен — из реестра.
3. Строка в `src/formats/index.ts`.
4. Дефолты текстов формата — в `config/copy.json` (по паре режим цены × язык).
5. `npm test` — реестр проверит всё перечисленное; `npm run test:render` — отрендерит новый формат.

Интерфейс, сервер, раскадровка и CLI подхватывают формат из реестра сами.

## Тесты

```bash
npm test             # быстрые (~40 с): цена и склейка настроек, реестры, таймлайн и укладка озвучки,
                     # очередь рендера и сроки на процессах, API лотов и обзоров (с настоящей обработкой
                     # тестового видео с поворотом) на временных папках, размытие фото
npm run test:render  # медленные (минуты): настоящий рендер каждого формата и обзора — кадры, длительность,
                     # ценовая сцена export vs domestic, ролик без музыки с беззвучной дорожкой (не GIF)
npm run test:all     # проверка типов + все тесты
```

Тесты входа, кабинетов и кредитов (`tests/server/auth.test.mjs`) идут на настоящем Postgres и
только с `TEST_DATABASE_URL` — своя база с правом создавать схемы, не общий Supabase. Без
переменной они пропускаются. Удобно — временный Postgres на своей машине:

```bash
initdb -D /tmp/pg -U postgres -A trust && pg_ctl -D /tmp/pg -o "-p 55432" start
TEST_DATABASE_URL=postgres://postgres@127.0.0.1:55432/postgres npm run test:all
```

Тесты API и фото работают во временных папках (`CONFIG_DIR`, `DATA_DIR`) и не трогают настоящие настройки и лоты.
Перед изменениями в сценах, музыке или сервере — прогонять **оба** набора. `npm test` рендер-тесты не запускает,
и на этом уже обожглись: после перехода на 60 кадров в рендер-тесте осталось деление на 30, и заметили это
только вручную. Всё, что зависит от частоты, берётся из `REVIEW_FPS`, а не пишется числом.

Тесты денег не стоят: вместо ElevenLabs поднимается подставной сервер, который отдаёт и разбор речи, и звук.

## Музыка

**Музыка из продукта убрана.** Причина простая: лицензионную музыку в соцсети без риска блокировки не вставить, а сгенерированная звучит дёшево. Выбора трека и громкости в интерфейсе больше нет — ни в профиле, ни в лоте. Трек, сохранённый в старых лотах и обзорах, в ролик и превью не попадает (`src/shared/nomusic.js`).

Ролики выходят **без музыки, но со звуковой дорожкой из тишины** (`enforceAudioTrack: true` в `server/renderer.mjs`): mp4 совсем без аудио Telegram, WhatsApp и некоторые площадки принимают за GIF, а с беззвучной дорожкой — это нормальное видео. Звук добавляется уже при публикации в TikTok/Instagram (там своя лицензионная библиотека).

Механизм музыки не удалён, а оставлен дремать: `src/shared/music.tsx`, `config/music.json`, `public/music/`. Если появится лицензионная музыка — вернуть выбор в интерфейс несложно. Пока `BackgroundMusic` без трека просто ничего не рисует.

## Контейнер и сервер

```bash
tools/vps-deploy.sh          # код → сервер, сборка образа там, перезапуск контейнера
```

Вручную то же самое:

```bash
docker build -t axis-video .
docker run -d --name axis-video --restart unless-stopped \
  -p 127.0.0.1:3210:3210 --env-file .env -v axis-data:/app/data \
  --memory=2g --memory-swap=2g --cpus=2 axis-video
```

Образ собирается **на сервере**: Mac это arm64, сервер x86_64, и образ с Mac там
не запустится. Уезжает код (`git archive`, ~6 МБ), собирается нативно за минуту.

Образ — 1,54 ГБ: Node, системные библиотеки для Chrome и сам браузер Remotion внутри.
Браузер кладётся на сборке специально: иначе Remotion качает 88 МБ при первом рендере,
уже после нажатия кнопки. Внутри образа свои ffmpeg и ffprobe (n7.1, из Remotion) —
контейнер проверен с `--network none`.

**В бою интерфейс отдаётся готовой статикой** из `dist/app`, и признак — `NODE_ENV=production`,
а не наличие папки. Локально ничего не меняется: `npm run app` по-прежнему поднимает Vite
с горячей перезагрузкой. Собрать интерфейс отдельно — `npm run build`.

`data/` подключается томом: исходники, рабочие копии, рендеры и логотипы переживают
обновление образа. Проверка живости ходит в `/api/config`.

**На сервере ставь `RENDER_CONCURRENCY=2`** (в образе уже так). Замер: при 8 рендер ест
2372 МБ, при 2 — 889 МБ, а время почти то же — 27 с против 30. Память растёт по потокам
линейно, скорость — нет; на машине с боевым сайтом восьмёрка не поместится.

**Вход по паролю (Basic Auth) — переменными `BASIC_AUTH_USER` и `BASIC_AUTH_PASS`.** Заданы
оба — сервер требует вход на всё, кроме `/healthz`; пусто (Mac) — без пароля. Нужно там, где
у инструмента публичный домен: логина внутри нет, а рендеры дорогие. Проверка живости ходит
в `/healthz` без пароля, поэтому она включена и на публичном домене.

**Прод отличается от дева одним признаком `NODE_ENV=production`:** карусель на сервере
без слайда истории (страховые случаи с датацентра не приходят — 6 слайдов вместо 7),
и пайплайн обзоров закрыт в интерфейсе — нет во вкладках, а прямая ссылка показывает «раздел
пока недоступен» (рендер обзора занял бы полмашины на час). Код обоих на месте. На Mac всё как раньше.

Входа по паролю по-прежнему нет, поэтому контейнер слушает `127.0.0.1` и наружу
не выставляется. Ходим туннелем:

```bash
ssh -L 3210:127.0.0.1:3210 axis-vps
```

Боевой `.env` лежит на сервере отдельно (права 600) и выкладкой не перезаписывается.
Это **не копия локального**: порт, адрес, режим, параллельность и путь к данным задаёт
образ, `CHROME_PATH` с Mac на Linux не годится, а `KMOTORS_API_URL` указывает на боевой
адрес сайта вместо локального порта.
