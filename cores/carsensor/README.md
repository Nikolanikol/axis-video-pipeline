# cores/carsensor — модуль-ядро источника «Япония»

Забирает машину с **carsensor.net** (カーセンサー, Recruit — крупнейшая витрина подержанных машин
японских дилеров; это **не аукцион**): характеристики, опции, фото ~2560×1920 с ролями от самого
дилера, оценку «カーセンサー認定». Сайт только японский — на английский и русский переводит само ядро
своими словарями (`src/dict.mjs`). Независимый модуль внутри KOK по общему контракту
**[cores/CONTRACT.md](../CONTRACT.md)**: прямой импорт точки входа, наружу — данные или `CoreError`.
Без зависимостей (Node 20+).

## Как вызывать

```js
import { getCar } from '../cores/carsensor/src/index.mjs';
const { data, warnings } = await getCar('https://www.carsensor.net/usedcar/detail/AU7375484964/index.html', { langs: ['en', 'ru'] });
```

В KOK это делает граница модуля `server/carsensor.mjs` (таймаут 45 с, `requestId`, CoreError → ответ
интерфейсу, курс ¥ → $ дня), переходник в `CarouselCar` — `src/shared/carsensorCar.js`.

Проверить из командной строки (из папки axis-video):

```bash
node cores/carsensor/bin/fetch.mjs <ссылка|номер> [ещё…] [--out out] [--lang en,ru,ja] [--no-photos] [--raw]
```

Пишет `out/<номер>/car.json` + `photos/`. Код выхода: 0 — всё забрано, 1 — ошибка хотя бы по одной
машине, 2 — неверный запуск. Переменные: `LOG_LEVEL`, `CARSENSOR_BASE` (подменить адрес сайта — для
проверки сбоев), `CARSENSOR_TIMEOUT_MS` (таймаут запроса, по умолчанию 15 000).

## Устройство

```
src/index.mjs         ТОЧКА ВХОДА: core, getCar(ref, {langs, signal, log}), checkUpstream()
src/upstream.mjs      страница машины: таймаут, повторы, ограничитель (2 запроса разом), сбои → коды контракта
src/parse.mjs         разбор HTML: чистые функции, не доверяют вёрстке
src/dict.mjs          словари: марки/модели, слова комплектаций, цвета, кузова, префектуры, опции, роли фото
bin/fetch.mjs         CLI через ту же точку входа
```

Машина = **один запрос** (~470 КБ HTML, 0,6–1,5 с): всё на одной странице, языки — наш перевод.
Без страницы машины нет — ошибка; цена, фото, опции, перевод — части: не нашлись — карточка
отдаётся с `warnings` (`PART_MISSING`/`PART_FAILED`). Карточки — в памяти 30 минут, одинаковые
одновременные запросы склеиваются.

## Ошибки и логи (проверено 12.10.2026)

Проверка на подставном сайте (`CARSENSOR_BASE` на свой сервер, который по номеру отвечает поломкой):

| что отвечает сайт | код ядра | повторы | статус в KOK |
|---|---|---|---|
| 403 | `UPSTREAM_BLOCKED` (error) | нет | 502 |
| страница с капчей | `UPSTREAM_BLOCKED` (error) | нет | 502 |
| 429 | `RATE_LIMITED` | 3 попытки | 429 |
| 500 | `UPSTREAM_UNAVAILABLE` | 3 попытки | 502 |
| 500, потом 200 | машина отдана со 2-й попытки | 1 повтор | 200 |
| обрыв соединения | `UPSTREAM_UNAVAILABLE` | 3 попытки | 502 |
| зависание | `UPSTREAM_TIMEOUT` | 3 попытки | 504 |
| 404 «掲載終了» | `NOT_FOUND` | нет | 404 |
| 200, но не страница машины | `UPSTREAM_BAD_RESPONSE` (error) | нет | 502 |
| нет цены, фото, опций | машина + 3 предупреждения `PART_MISSING` | — | 200 |
| сломан разбор одной части | машина + `PART_FAILED` + строка error `parse.failed` | — | 200 |

Найдено этой проверкой и исправлено: код символа вне Юникода в подписи дилера («&#99999999;») ронял
разбор фото.

Строки лога (JSON, одна на событие; `LOG_LEVEL=debug` — с удачными запросами):

```
debug upstream.ok     {ref, attempt, ms, kb}               запрос к сайту удался: время и размер страницы
warn  upstream.retry  {ref, attempt, code, ms, waitMs}     повтор после сбоя
error parse.failed    {ref, part, error со стеком}          сломался разбор части — чинить parse.mjs
warn  dict.missing    {ref, part, words}                   незнакомые слова — дописать dict.mjs
error car.internal    {ref, error со стеком}                баг ядра (INTERNAL)
— граница KOK (server/carsensor.mjs) —
warn  part.missing    {code, part, message}                каждое предупреждение карточки
info  car.ok          {ref, warnings, tookMs}              машина отдана
warn/error request.failed {ref, code, tookMs, error}       отказ: warn — ожидаемое, error — чинить
```

Все строки одного запроса связывает `requestId`. Найти в логах Coolify всё по одной машине:
`grep '"core":"carsensor"' | grep <requestId>`.

## Откуда данные (разведка 12.10.2026)

- **Доступ:** обычный запрос без кук, входа и проверки на бота — с Mac и с axis-vps одинаково.
  robots.txt ничего не запрещает. Официальный API Recruit для Carsensor закрыт (отвечает страницей
  ошибки), внутреннего JSON у страницы нет. Пользовательское соглашение Recruit не читали.
- **Адрес:** `https://www.carsensor.net/usedcar/detail/<номер>/index.html`, номер — `AU` + 10 цифр.
  Хвост `?dspn=…` в ссылках из поиска — метка выдачи, на страницу не влияет.
- **Снятая машина:** HTTP 404 со страницей «掲載終了» → `NOT_FOUND`.

| что | где на странице | ловушки |
|---|---|---|
| название, цена, цвет, продавец | JSON-LD `Product` | `price` — цена машины («車両本体価格»), в ¥ |
| характеристики | пары `<th>`/`<td>` | «駆動方式» дважды: сначала 2WD/4WD объявления, потом «前輪駆動(FF)» каталога — берём первое |
| цена с японскими сборами | th «支払総額（税込）» | вёрстка «419 .9 万円» с пробелом перед дробью |
| латинские марка и модель | ссылка `/catalog/<марка>/<модель>/<код>/` | ищем ссылку с кодом модели этой машины (JSON-LD `model`, «F004»); слаги бывают с опечаткой (`cayene`), сокращением (`c_class_wgn`), маркой впереди (`lexus_ux`) — правит `MODELS` в dict.mjs |
| комплектация | JSON-LD `name` до первого полноширинного пробела «　» | после него — реклама дилера; марку и модель отрезаем по японским названиям из `brand[]` |
| опции | `h3.equipmentList__title` + `li.equipmentList__item`, есть — класс `--active` | 102 пункта в 5 группах; составные «エアバッグ：運転席/助手席/サイド/カーテン», «－» в части = нет |
| фото | `<a data-photohq data-title data-categoryname>` | см. ниже |
| оценка «認定» | блок после «カーセンサー認定評価を受けた» | заголовок «車両品質評価詳細情報» раньше встречается в меню вкладок |
| префектура | хлебные крошки «ハリアー・東京都の中古車» | «北海道» — целиком, остальные без «都/府/県» |

**Пробег:** «4.7万km» = 47 000 км (万 — десять тысяч), «116km» — как есть.

**Цена:** `price.amount` — «車両本体価格», цена машины без японских сборов за регистрацию: машину
вывозят, в Японии её не регистрируют. `price.totalJpy` — «支払総額» со сборами, для справки. В $ ядро не
переводит — это делает KOK по своему курсу дня (`server/carsensor.mjs`).

## Фото

`data-photohq` с `?impolicy=car_002` — **2560×1920** (~600 КБ); без параметров — 640×480 (так их
берёт сетка выбора фото). У каждого кадра:

- `data-title` — чей кадр: «本体写真» (главное объявления), «基本プラン» (галерея), «Ａプラン»/«Ｂプラン» (допродажи
  дилера: покрытие стекла и т.п.), «カーセンサーアフター保証» (баннер гарантии), «本体動画» (видео). Берём
  главное и галерею;
- `data-categoryname` — **подпись ракурса от самого дилера**: «左斜前» (перед ¾ слева), «正面», «後»,
  «運転席», «インパネ全体», «エンジンルーム»… — ~40 значений, все в `PHOTO_ROLES` (dict.mjs). Поэтому
  `source: 'listing'`: роль из разметки объявления, а не догадка по номеру.

**ВАЖНО — плашка дилера на главном фото.** У всех четырёх проверенных дилеров (SUV LAND, BAIZE,
Garden, Nissan Fukuoka) на «本体写真» впечатан баннер с логотипом магазина. Ядро помечает его
`ad: false, sticker: true`; обложка — перед ¾ из галереи (там чисто, на номере — табличка дилера).

Не для рекламы (`ad: false`): «販促用画像» (рекламные баннеры — треть галереи!), «未設定»/«その他» (дилер
не подписал: и машина, и баннеры вперемешку), «付属品» (ключи, книжки), «ダメージ・汚れ» (повреждения),
«店舗» (витрина), мелкие кнопки, ETC, подкапотное, днище.

Известное: дилеры иногда кладут один и тот же кадр дважды под разными адресами — по адресу дубль не
отличить.

## Перевод

Марка и модель — из латинского слага каталога (`brandFromSlug`, `modelFromSlug`). Комплектация —
по словам: латиница как есть, катакана — словарём `KANA_WORDS` (самое длинное совпадение), чего нет —
по слогам (`romaji`, Хепбёрн): лучше «Joi» на слайде, чем иероглифы. Слитно: «xドライブ» → «xDrive»
(после строчной), «PZターボ» → «PZ Turbo», «ティプトロニックS» → «Tiptronic S». Иероглифы («後期» — после
рестайлинга) — словарём, незнакомые выбрасываем. Топливо — по «エンジン種別» (тип двигателя), а не
«使用燃料» (сорт: «レギュラー» и «ハイオク» — оба бензин). Коробка: механика — только «MT» без «モード付»
(«フロアMTモード付CVT» — вариатор с ручным режимом). Цвет — первое цветовое слово в заводском названии
(«プレシャスブラックパール» → Black; «パールホワイト» → White). Опции — `OPTIONS` и `COMPOSITE` на en и ru.

Слово, которого нет в словаре опций, ядро отдаёт японским и пишет в лог `dict.missing` — его надо
добавить в dict.mjs. Переходник KOK японское на слайд не пускает.

## Карточка (`data`)

```
source, ref («AU7375484964»), fetchedAt
urls.ad                         страница объявления
ids                             brandSlug, modelSlug, catalogModel («F004»), shopUrl
price                           { amount (¥, цена машины), currency: 'JPY', totalJpy (со сборами) }
mileageKm
photos[]                        { url (2560), preview (640), label (подпись дилера), category, angle,
                                  ad, source: 'listing', main?, sticker?, caption }
repairHistory                   修復歴: false — не было кузовного ремонта, true — был, null — не указано
certification                   { score: «4.5»/«S»/«R», inspectedAt, repairHistory, summary (яп.) } | null
byLang.en / .ru                 car: { title, brand, model, grade, year, regDate, mileageKm,
                                  displacementCc, fuel, transmission, body, drive, color, seats, doors,
                                  steering, city }, options: [{ group, name, ja }]
byLang.ja                       car: всё как на сайте (японские значения характеристик)
```

`byLang.ru.car` — та же английская карточка (слова словаря слайдов KOK переводит сам), по-русски
только опции. Оценку и историю в рекламе не показываем — решение владельца 11.10 для всех источников.

## Проходка 12.10.2026

25 машин 12 марок (Toyota, Lexus, Honda, Nissan, Mazda, Subaru, Suzuki, Daihatsu, Mitsubishi, BMW,
Mercedes-Benz, Volkswagen, Porsche): кей-кары, минивэны, гибриды, дизели, механика. Все разобраны;
названия латиницей — от «Toyota Harrier 2.5 Hybrid Z Leather Package» до «Daihatsu Mira e:S 660 L SAIII»;
на 24 из 25 все включённые опции переведены (последняя — подъёмное сиденье для инвалидов, добавлено);
у всех оценка «認定» (3–5); фото 31–80, для рекламы годится 12–53. Ошибки проверены руками: неверная
ссылка и язык → `BAD_INPUT`, снятая машина → `NOT_FOUND`, закрытый порт → `UPSTREAM_UNAVAILABLE`,
таймаут → `UPSTREAM_TIMEOUT` после трёх попыток.
