# Касса NOWPayments — USDT в сети TRON

Модуль-касса KOK по контракту `cores/PAYMENTS.md` (версия pay-1). Принимает оплату тарифов в
USDT TRC20 через [NOWPayments](https://nowpayments.io). Не знает про кредиты, тарифы и базу —
только API кассы. Что делать с деньгами, решает KOK: `server/payments.mjs`.

## Почему NOWPayments и USDT (решение владельца 12.10.2026)

Владелец — физлицо в Южной Корее без российского номера и ИП; клиенты — в основном из РФ.
Российские кассы (Robokassa, ЮKassa, CloudPayments, Prodamus) требуют российский статус —
верификация не проходит. Для приёма только крипты NOWPayments документов не просит. USDT ≈ $1:
у клиента нет курсового риска, у нас — пересчёта.

Отвергнуты: FreeKassa (массовые жалобы на заморозку денег), Cryptomus (рекордный штраф FINTRAC
в 2025-м). Рубли придут второй кассой — AnyPay (`cores/pay-anypay`, когда пройдёт модерацию).

## Файлы

| файл | что |
|---|---|
| `src/index.mjs` | точка входа: `core`, `createClient()`, `toPayment()` |

| `src/status.mjs` | статусы кассы → общие статусы |
| `bin/check.mjs` | проверка руками: связь, ключ, монета, платёж по номеру |

## Как идёт оплата

1. KOK вызывает `createInvoice({orderId, amount, …})` → `POST /v1/invoice`. Счёт — в долларах
   (`price_currency: usd`), платить — только `usdttrc20`, комиссию кассы платим мы
   (`is_fee_paid_by_user: false`). Ответ — `invoice_url`: страница кассы с адресом, суммой, QR.
2. Клиент переводит USDT. Касса шлёт уведомления (IPN) на `notifyUrl` при каждом изменении
   статуса: `waiting → confirming → confirmed → sending → finished`.
3. KOK читает уведомление `readNotification(body, signature)` — проверка подписи, общий вид — и
   перед начислением спрашивает платёж `getPayment(paymentId)` → `GET /v1/payment/:id`.

## Статусы

| у кассы | общий | смысл |
|---|---|---|
| `waiting` | `waiting` | ждём перевод |
| `confirming`, `confirmed`, `sending` | `confirming` | перевод идёт, деньги ещё не у нас |
| `partially_paid` | `partial` | пришло меньше суммы счёта |
| `finished` | `paid` | деньги у нас — **единственный статус для начисления** |
| `failed` | `failed` | ошибка кассы |
| `refunded` | `refunded` | деньги вернули клиенту |
| `expired` | `expired` | время на оплату вышло (7 дней) |
| другое | `unknown` | новое слово кассы — не начислять, смотреть лог |

## Подпись уведомлений

Заголовок `x-nowpayments-sig` = HMAC-SHA512(`JSON.stringify(тело с ключами по алфавиту на всех
уровнях)`, IPN secret), hex. Сравнение — за постоянное время. Пустой секрет — подпись всегда
неверна (HMAC с пустым ключом может посчитать кто угодно).

## Ошибки

| что случилось | код | повтор |
|---|---|---|
| 401/403 — ключ не принят, касса не настроена | `UPSTREAM_BLOCKED` | нет, нужен человек |
| 400 — сумма меньше минимальной, монета выключена | `BAD_INPUT` | нет |
| 404 — нет платежа | `NOT_FOUND` | нет |
| 429 | `RATE_LIMITED` | да |
| таймаут 20 с | `UPSTREAM_TIMEOUT` | да |
| сеть, DNS, 5xx | `UPSTREAM_UNAVAILABLE` | да |
| не JSON, нет нужных полей, адрес оплаты не https | `UPSTREAM_BAD_RESPONSE` | нет, чинить модуль |
| неверная подпись уведомления | `BAD_INPUT` | — |

Повторы (до 3, пауза 0,5 → 1,5 с) — **только у чтения** (`GET`). Счёт не повторяется: при
оборванном ответе повтор создал бы второй счёт, о котором клиент не знает.

## Ловушки (на чём уже спотыкались)

- **Песочница — отдельный аккаунт** (`account-sandbox.nowpayments.io`) со своими ключами и адресом
  API `api-sandbox.nowpayments.io`. Боевой ключ в песочнице — 403, и наоборот.
- **В песочнице `actually_paid` = 0 даже у оплаченного** платежа. Начисление поэтому смотрит на
  статус `finished`, а не на «сколько пришло».
- **Платёж через API песочницы можно провести сценарием** `case: "success"` (`POST /v1/payment`) —
  так проверяли полный путь без настоящих денег. Через ~30 с он становится `finished`.
- **Номер платежа — число**, в ответах иногда строкой. Модуль приводит к строке.
- **Кабинет кассы может разрешать больше монет**, чем USDT TRC20: счёт всё равно выставляется с
  `pay_currency: usdttrc20`, а KOK при сверке проверяет монету.
- **Хранение средств (custody) у кассы включено** — деньги копятся на балансе NOWPayments (акция
  «без комиссии сети» на 60 дней с 12.10). Выводить на свой кошелёк регулярно: по правилам касса
  может закрыть аккаунт. Адрес вывода — в белом списке, отключение списка — 48 часов.
