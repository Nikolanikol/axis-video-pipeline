# cores/che168 — модуль-ядро источника «Китай»

Забирает машину с **che168.com** (二手车之家, площадка объявлений дилеров Autohome): характеристики,
опции, фото в оригинале и лист осмотра — на английском и русском (и ещё 7 языках в запасе).
Независимый модуль внутри KOK по общему контракту **[cores/CONTRACT.md](../CONTRACT.md)**: вызывается
прямым импортом точки входа, наружу — только данные или `CoreError`. Без зависимостей.

## Как вызывать

```js
import { getCar } from '../cores/che168/src/index.mjs';
const { data, warnings } = await getCar('https://www.che168.com/dealer/513988/60154824.html', { langs: ['en', 'ru'] });
```

В KOK это делает граница модуля `server/che168.mjs` (таймаут 45 с, `requestId`, CoreError → ответ
интерфейсу), переходник в `CarouselCar` — `src/shared/che168Car.js`.

Проверить из командной строки (из папки axis-video):

```bash
node cores/che168/bin/fetch.mjs <ссылка|номер> [ещё…] [--out out] [--lang en,ru] [--no-photos] [--raw]
```

Пишет `out/<номер>/car.json` + `photos/`. Код выхода: 0 — всё забрано, 1 — ошибка хотя бы по одной
машине, 2 — неверный запуск. Переменные: `LOG_LEVEL`, `CHE168_API_BASE` (подменить адрес API —
для проверки сбоев), `CHE168_TIMEOUT_MS` (таймаут одного запроса, по умолчанию 15 000),
`CHE168_STUDIO_DEALERS` (студийные площадки Autohome, через запятую).

## Устройство

```
src/index.mjs         ТОЧКА ВХОДА: core, getCar(ref, {langs, signal, log}), checkUpstream()
src/upstream.mjs      клиент API: таймаут, повторы, ограничитель (4 запроса разом), сбои → коды контракта
src/parse.mjs         разбор ответов и роли фото: чистые функции, не доверяют форме данных
bin/fetch.mjs         CLI через ту же точку входа
../kit/               общее для всех ядер: CoreError и коды, JSON-логи, ограничитель
```

Что обязательно и что нет: без основной карточки (`carinfo`) машины нет — это ошибка. Параметры,
опции, лист осмотра, фото — части: не пришли — карточка отдаётся, в `warnings` строка
`PART_MISSING`/`PART_FAILED` с `part`. Разбор каждой части отдельно в `try`: поменял che168 формат
опций — сломаются опции, а не вся машина. Готовые карточки — в памяти 30 минут (до 500 штук),
одинаковые одновременные запросы склеиваются в один.

## Проверка ошибок (11.10.2026)

Через подменённый API (`CHE168_API_BASE`): нет DNS и закрытый порт → `UPSTREAM_UNAVAILABLE`,
403 и страница «Security Verification» → `UPSTREAM_BLOCKED`, 429 → `RATE_LIMITED`, 500 →
`UPSTREAM_UNAVAILABLE`, HTML / JSON без `returncode` / `result` строкой → `UPSTREAM_BAD_RESPONSE`,
зависание → `UPSTREAM_TIMEOUT`, поля не тех типов → карточка с предупреждениями, без падения.
Кривая ссылка, мусор, неизвестный язык → `BAD_INPUT`; несуществующая машина → `NOT_FOUND`;
переполнение очереди → `OVERLOADED`. Со стороны KOK — у каждого кода понятный текст, KOK жив.

## Откуда данные и почему так

У che168 три лица, и два из них закрыты:

| что | доступ простым запросом |
|---|---|
| `www.che168.com` — китайский сайт | ❌ JS-проверка на бота (куки `__tst_status`, `EO_Bot_Ssid`) |
| `m.che168.com`, `global.che168.com` — страницы | ❌ «Security Verification» |
| **`globalapi.che168.com/api/v1`** — API международной версии | ✅ открыт, JSON, без ключа |

Ядро ходит только в API — проверку на бота не обходим, браузер не нужен. Проверено 11.10.2026
с Mac (Корея) и с axis-vps (Германия): отвечает одинаково, гео-блокировки нет.

**Номер машины (infoid) общий** у китайского сайта и международной версии, поэтому годится ссылка
с любой: `…/dealer/<дилер>/<номер>.html`, `…/detail/<номер>`, `…?infoid=<номер>` или просто число.

## Запросы API

Все — `GET https://globalapi.che168.com/api/v1/<путь>?_appid=global.pc&language=<язык>&…`,
ответ `{returncode, message, result}`, успех — `returncode: 0`.

| путь | что отдаёт |
|---|---|
| `carinfo/<infoid>` | карточка: марка/серия/комплектация, даты, пробег, цена $, двигатель, коробка, привод, руль, кузов, цвет, размеры, город, VIN со звёздочками, фото (`catepiclist`), экспортный и портовый сборы, ссылка на отчёт. Несуществующий номер → `result: null` |
| `specparam?specid=` | тех. параметры по комплектации (6 групп), в т.ч. цена новой в ¥ |
| `specconfig?specid=` | опции по комплектации (15 групп) |
| `getcarreport?infoId=` | лист осмотра. **Параметр `infoId` с большой I** — с `infoid` ответ «无效的车源ID» |
| `lang` | языки: zh, en, ru, ar, fr, es, pt, de, it |

**Языки.** Международная версия переведена Autohome сама — свои словари не нужны. Сейчас берём
`en` и `ru` (под «Язык постов» профиля KOK). В запасе, когда понадобятся: `ar` арабский, `fr` французский,
`es` испанский, `pt` португальский, `de` немецкий, `it` итальянский, `zh` китайский оригинал.
Сервис примет любой из них: `?lang=en,ru,ar`.

Ещё есть (не используем): `search`, `brand`, `series`, `recommend`, `shipping/*`, `country/*`.

## Карточка (`data`)

```
source, ref (строкой), fetchedAt
urls.global / urls.cn          ссылки на объявление
ids                            brandid, seriesid, specid, dealerid, cityid
price                          { amount — цена международной версии, currency: "USD", exportFee, portFee }
mileageKm
photoSet                       studio | dealer — точные роли или догадка по положению
photos[]                       { url — оригинал, preview — webp 1400, category, angle, ad, source, sticker?; в CLI ещё file }
certified                      есть ли настоящий лист осмотра
byLang.<en|ru>
  car          title, brand, series, trim, modelYear, regDate, productionDate, mileageKm, fuel,
               engine, transmission, drive, steering, body, class, seats, doors, color,
               dimensionsMm (Д*Ш*В), curbWeightKg, city, vinMasked, remark
  newPriceCny  цена новой, ¥
  specs[]      { group, items: [{ name, value }] }
  options[]    { group, items: [{ name, value }] } — «●» в базе, «○» за доплату, бывает «Перед ●/Зад -»
  inspection   null или { reportUrl, clean, categories[{id, name, pointsChecked, faults}], pointsChecked,
               faults[{pointId, categoryId, point, defect, photos[]}], photos[], points[] }
```

«-», «--» и пустые строки из API превращаются в `null`; ведущие пробелы в названиях (« BMW») срезаны.
**Лист осмотра в рекламе не показываем** (решение 11.10): продукт рекламный, что показывать — решает
покупатель. Ядро его отдаёт — для дилера.

## Где легко ошибиться

- **Цена.** Решено 11.10: в пайплайн идёт `price.amount` (USD) из API. Это цена международной версии, она **не равна** цене дилера на китайском
  сайте: BMW 60154824 — $17 800 в API и ¥116 800 (≈ $16 400) на www.che168.com. Похоже, в долларовую
  уже заложена наценка экспортного сервиса Autohome. Цены в юанях API не отдаёт.
- **Лист осмотра.** `getcarreport` возвращает 95 точек проверки для **любого** номера, даже
  несуществующего — это шаблон, а не результат. Настоящий отчёт только у сертифицированных машин
  (`certification_status = 1` и непустой `report_url`); у остальных ядро отдаёт `inspection: null`.
  Находки — `faultList`/`faultPicList`; непустых пока не встречали, формат не известен — отдаём как есть.
  Полный отчёт с фото — страница `reportUrl` (activitym.che168.com), её не разбираем.
- **Фото.** API даёт уменьшенные webp (`…/1400x0_c42_autohomecar__X.jpg.webp`). Оригинал — с приставкой
  **`0x0_`** (`…/0x0_autohomecar__X.jpg`): исходник дилера. Без приставки CDN отдаёт тот же размер, но
  **пережатый заново** (квантование JPEG 13–16 против 2–6, файл на 30–150% легче) — на видео рябит
  (найдено 11.10 по жалобе на рябь в галерее). Размер — какой загрузил дилер: бывает 2048×1536 (BMW), бывает 1024×768 (Jaguar) —
  больше загруженного не получить. Приставка `480x0_c42_` — миниатюра 480 px (~40 КБ).
  Разметки ракурсов в API нет: группа фото всегда одна и без названия (40 машин из 40, 11.10).
- **Чего нет вовсе:** истории ДТП и обслуживания (на китайском сайте — платный запрос), числа владельцев
  (на китайском сайте есть 过户次数, в API нет), полного VIN.
- **Не переведено API:** `steering` («Left»), `city` («xian») приходят по-английски и на ru.

## Фото: роли без распознавания

Решение 11.10: распознавание моделями не делаем — проект пока максимально бесплатный. Ядро
размечает фото так (`photoRoles` в `src/parse.mjs`), у каждого: `category` (exterior | interior |
engine | detail | unknown), `angle`, `ad` (годится ли для рекламы), `source` (studio | position):

- **Студийный набор** (`photoSet: "studio"`) — экспортные площадки Autohome (дилеры 466721 и 478339,
  почти половина объявлений) снимают каждую машину в одном белом зале ровно 24 кадрами в постоянном
  порядке. Сверено на 9 машинах двух площадок — номер = ракурс:
  1 перед ¾ (**наклейка** «保实表 10年包退 / 优信 国际车», `sticker: true`, в рекламу нет) · 2 зад ¾ · 3 перед ·
  4 зад · 5 торпедо · 6 мотор · 7 фара · 8 открытая дверь · 9 кнопки двери · 10 передние сиденья ·
  11 руль и приборы · 12 экран · 13 селектор · 14 люк · 15 задний ряд · 16 багажник · 17 колесо ·
  18 ручка · 19 ключ · 20 сиденье крупно · 21 блок света · 22 место водителя · 23 задний ряд сбоку ·
  24 маркировка шины. Новая такая площадка — в `STUDIO_DEALERS` или `CHE168_STUDIO_DEALERS=id,id`.
- **Дилерский набор** (`photoSet: "dealer"`) — порядок свой: первые 4 кадра считаем кузовом
  (по образцам — кузов 3–5 первых), остальное `unknown`. Бывают водяные знаки и баннеры дилера
  с иероглифами на кузовных фото, бывает днище — по положению этого не отличить.

**На будущее** (когда понадобится качество и появятся агенты): Claude Haiku по миниатюрам 480 px
(~$0,01 за машину; заодно водяные знаки, днище, бумаги, выбор «красивых») или локальный CLIP в ядре
(бесплатно, но +~100 МБ модели и ~300 МБ памяти, хуже различает ракурсы).

## Проходка 11.10.2026: 13 машин

BMW 5 Series, Jaguar F-PACE, BMW iX3 (электро), Honda Odyssey (гибрид), Chery Tiggo 8 и Roewe RX9 (китайские),
Subaru BRZ (купе), Maserati Levante, MINI Paceman 2013, Mercedes SL 2011, Skoda Kodiaq (7 мест),
Range Rover Evoque, Lexus RX 2013. По одной, с паузой 1,5 с; без кэша машина (en+ru) — 3–10 с вместе с фото.

**Устойчиво, можно опираться:**
- `carinfo` у всех одинаковый — 39 ключей, ни один не пропал. Поля карточки заполнены у всех,
  кроме `curbWeightKg` (1 из 13) и `remark` (пусто у всех).
- Комплектация (`trim`) всегда начинается с модельного года: «2018 530Li…» — год брать отсюда.
- Точный объём и мощность — в параметрах: `Displacement (mL)` и `Maximum horsepower (Ps)` (у всех ДВС);
  у электро их нет, есть группы «Electric Motor», «Battery & Charging». `engine` у электро — null.
- Опции: 14 групп, значения только «●», «○», «-» и составные «Перед ●/Зад -», «Основной●/Дополнительный-».
- Сборы одинаковые у всех: экспорт $400, порт $530.

**Различается или ловушки:**
- Серия то с маркой («BMW 5 Series»), то без («Levante», «Tiggo 8», «Kodiaq») — заголовок собираем сами (`title`).
- В параметрах «нет данных» бывает и «-», и «--» — оба → null.
- Не переведено на ru: `steering` («Left»), `city` («xian»). Названия моделей и комплектаций — латиницей
  на всех языках; в `engine` ru встречается то «л.с.», то «HP», в en — «hp», «HP», «horsepower».
- **Фото — два вида наборов.** «Студийный» (Autohome/优信, белый зал, 24 шт., 1024×768): порядок
  постоянный — 1 перед ¾, 2 зад ¾, 3 перед, 4 зад, 5 торпедо, 6 мотор, 7 фара, 8 дверь…, но **на первом
  фото — китайская наклейка** («保实表 10年包退», «优信 | 国际车»). «Дилерский» (салон дилера, 9–17 шт.,
  1440–2048 px): порядок свой — первое обычно перед ¾, заднего ракурса может не быть вовсе.
- **Лист осмотра** — у 12 из 13 (всё, что берём из поиска с `report_status=1,3`, сертифицировано).
  Находки нашлись у двух: Subaru BRZ — 4 деформации силовых элементов (битая), Evoque — изменение
  цвета коврика (подтопление). Фото находок — static.chaboshi.cn, 1536×2048, открыты.
